# Assets

Ten katalog sluzy do agregowania materialow zrodlowych i eksportow dla strony Persooa.

Zasada:

- `source/` zawiera materialy otrzymane od klienta i pliki robocze.
- `exports/` zawiera zoptymalizowane pliki przygotowane do uzycia.
- Pliki produkcyjne trafiaja dopiero do `public/`.

Nie wrzucaj do `public/` plikow bez sprawdzenia licencji, zgody publikacji i optymalizacji.
