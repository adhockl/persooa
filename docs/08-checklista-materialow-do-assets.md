# Checklista materialow do dostarczenia przez klienta

## 1. Cel dokumentu

Ten dokument opisuje, jakie materialy klient powinien dostarczyc do przygotowania nowej strony Persooa.

Materialy zrodlowe beda agregowane w katalogu:

```txt
assets/source/
```

Po weryfikacji, optymalizacji i zatwierdzeniu wybrane pliki zostana przygotowane jako produkcyjne assety strony.

## 2. Jak najlepiej przekazac materialy

Rekomendowany sposob przekazania:

1. Link do Figma brandbooka.
2. Paczka ZIP z logo Persooa.
3. Paczka ZIP z fontami.
4. Paczka ZIP ze zdjeciami zespolu i biura.
5. Paczka ZIP z logotypami klientow.
6. Link lub eksport assetow z Webflow.
7. Dokument lub arkusz z potwierdzeniem, ktore materialy sa zatwierdzone do publikacji.

Nazwy paczek:

```txt
persooa-brandbook-YYYY-MM-DD.zip
persooa-logo-YYYY-MM-DD.zip
persooa-fonts-YYYY-MM-DD.zip
persooa-photos-YYYY-MM-DD.zip
persooa-client-logos-YYYY-MM-DD.zip
persooa-webflow-assets-YYYY-MM-DD.zip
```

## 3. Figma brandbook

Prosimy dostarczyc:

- link do pliku Figma,
- informacje, ktory plik/frame jest aktualnym brandbookiem,
- dostep `view` lub `edit`,
- informacje, czy Figma zawiera finalne kolory,
- informacje, czy Figma zawiera finalna typografie,
- informacje, czy Figma zawiera komponenty UI,
- informacje, czy Figma zawiera dark mode lub dark sections,
- informacje, czy Figma jest zgodna z projektem w Webflow.

Preferowana forma:

```txt
Link do Figma + krotki opis, ktore elementy sa finalne
```

## 4. Logo Persooa

Prosimy dostarczyc:

- logo podstawowe,
- logo poziome,
- logo pionowe, jezeli istnieje,
- sygnet / symbol, jezeli istnieje,
- wersje na jasne tlo,
- wersje na ciemne tlo,
- wersje monochromatyczne,
- favicon,
- social media / Open Graph image, jezeli istnieje.

Preferowane formaty:

```txt
SVG - najlepszy format dla logo
PNG - tylko jako dodatkowy format
```

Nazewnictwo:

```txt
persooa-logo-primary.svg
persooa-logo-light.svg
persooa-logo-dark.svg
persooa-symbol.svg
persooa-favicon.svg
persooa-og-image.png
```

## 5. Fonty

Prosimy dostarczyc:

- nazwe fontu podstawowego,
- nazwe fontu pomocniczego, jezeli istnieje,
- pliki fontow,
- informacje o wagach fontu,
- informacje o licencji webowej,
- informacje, czy font moze byc hostowany lokalnie na stronie,
- link do zrodla/licencji.

Preferowany format:

```txt
.woff2
```

Akceptowalne pomocniczo:

```txt
.otf
.ttf
```

Wazne:

> Nie mozemy wdrozyc fontu na stronie bez potwierdzenia licencji webowej.

## 6. Paleta kolorow i zasady brandowe

Prosimy dostarczyc:

- kolory podstawowe,
- kolory pomocnicze,
- kolory tla,
- kolory tekstu,
- kolory akcentowe,
- kolory dla dark mode lub dark sections,
- zasady stosowania kolorow,
- przyklady poprawnego i niepoprawnego uzycia brandu, jezeli istnieja.

Preferowana forma:

```txt
Figma styles / brandbook / tabela HEX
```

Przyklad:

```txt
Primary: #000000
Accent: #00B8FF
Background: #FFFFFF
```

## 7. Zdjecia zespolu

Prosimy dostarczyc:

- zdjecia zarzadu,
- zdjecia zespolu,
- zdjecia osob, ktore maja pojawic sie na stronie,
- imie i nazwisko kazdej osoby,
- stanowisko,
- informacje, ktore zdjecia sa zatwierdzone do publikacji,
- potwierdzenie zgody na wykorzystanie wizerunku.

Preferowane formaty:

```txt
JPG lub PNG w wysokiej rozdzielczosci
```

Nazewnictwo:

```txt
imie-nazwisko-stanowisko.jpg
arkadiusz-seredyn-ceo.jpg
remigiusz-wojtczak-cso.jpg
```

Wazne:

> Do strony produkcyjnej przygotujemy zoptymalizowane wersje WebP/AVIF. Prosimy dostarczyc oryginaly w jak najlepszej jakosci.

## 8. Zdjecia biura i materialy firmowe

Prosimy dostarczyc:

- zdjecia biura,
- zdjecia zespolowe,
- zdjecia ze spotkan lub eventow,
- zdjecia przestrzeni pracy,
- zdjecia, ktore moga zostac uzyte na stronie "O nas",
- informacje, ktore zdjecia sa zatwierdzone do publikacji.

Preferowane formaty:

```txt
JPG lub PNG w wysokiej rozdzielczosci
```

Nazewnictwo:

```txt
persooa-office-01.jpg
persooa-office-02.jpg
persooa-team-01.jpg
persooa-event-01.jpg
```

## 9. Logotypy klientow

Prosimy dostarczyc:

- logotypy klientow,
- informacje, ktore logotypy mozna pokazac publicznie,
- informacje, gdzie mozna je pokazac,
- informacje, czy mozna je pokazac w case studies,
- informacje, czy mozna je pokazac na homepage,
- informacje, czy mozna je pokazac w materialach sprzedazowych.

Preferowany format:

```txt
SVG
```

Akceptowalne:

```txt
PNG z przezroczystym tlem
```

Nazewnictwo:

```txt
nazwa-klienta-logo.svg
```

Przyklad:

```txt
orange-logo.svg
homla-logo.svg
coccodrillo-logo.svg
```

Wazne:

> Nie publikujemy logotypow klientow bez potwierdzenia prawa do ich uzycia.

## 10. Partnerzy technologiczni

Prosimy dostarczyc:

- liste partnerow technologicznych,
- logotypy partnerow,
- informacje, czy mozna uzywac ich logotypow,
- zasady partnerskie dotyczace ekspozycji logo, jezeli istnieja.

Przyklady:

```txt
Salesforce
Adobe
Oracle
Synerise
```

## 11. Case studies

Prosimy dostarczyc materialy do case studies:

- nazwa klienta,
- branza,
- problem/wyzwanie,
- opis wdrozenia,
- wykorzystane technologie,
- wyniki liczbowe,
- okres, ktorego dotycza wyniki,
- cytat klienta, jezeli jest dostepny,
- logo klienta,
- zgoda na publikacje,
- ograniczenia prawne lub NDA.

Wazne:

> Wyniki liczbowe, logotypy i cytaty klientow musza byc zatwierdzone do publikacji.

## 12. Materialy z Webflow

Prosimy dostarczyc:

- link do projektu Webflow,
- informacje, czy Webflow jest finalnym zrodlem contentu,
- informacje, czy Webflow jest finalnym zrodlem designu,
- eksport grafik z Webflow,
- screenshoty najwazniejszych sekcji,
- informacje, ktore sekcje sa zatwierdzone,
- informacje, ktore sekcje sa robocze.

Wazne:

> Webflow traktujemy jako zrodlo contentu i/lub referencje designu, ale przed wdrozeniem musimy sprawdzic zgodnosc z SEO i brandbookiem.

## 13. Ilustracje AI

Klient chce nowy styl ilustracji generowanych przez AI.

Prosimy dostarczyc:

- przyklady ilustracji, ktore sie podobaja,
- przyklady ilustracji, ktorych nalezy unikac,
- opis oczekiwanego stylu,
- informacje, gdzie ilustracje maja byc uzyte,
- informacje, czy maja byc bardziej abstrakcyjne, technologiczne, produktowe czy lifestyle,
- informacje, czy maja miec wersje jasna i ciemna.

Proponowane obszary ilustracji:

- hero strony glownej,
- Marketing Automation 2.0,
- Program Lojalnosciowy,
- AI Search,
- Integracja danych,
- Personalizacja AI,
- ROI w 90 dni,
- Growth Hub.

## 14. Ikony

Prosimy dostarczyc:

- istniejący zestaw ikon, jezeli firma go posiada,
- zasady stylu ikon,
- informacje, czy ikony maja byc liniowe, wypelnione czy mieszane,
- informacje, czy ikony maja byc generowane od nowa.

Jezeli klient nie posiada ikon:

- przygotujemy zestaw ikon zgodny z design systemem,
- mozemy oprzec sie na bibliotece ikon pasujacej do Tailwind/React/Astro.

## 15. Wideo i animacje

Jezeli sa dostepne, prosimy dostarczyc:

- filmy firmowe,
- animacje produktowe,
- nagrania eventowe,
- materialy promocyjne,
- informacje, czy mozna je publikowac,
- wersje z napisami, jezeli istnieja.

Preferowane formaty:

```txt
MP4
WebM
```

Wazne:

> Wideo musi byc zoptymalizowane, aby nie spowalniac strony.

## 16. Dokument z prawami do materialow

Prosimy przygotowac prosty dokument lub arkusz:

```txt
materialy-prawa-i-zgody.xlsx
```

Kolumny:

- nazwa materialu,
- typ materialu,
- wlasciciel,
- zgoda na publikacje,
- gdzie mozna uzyc,
- ograniczenia,
- data zatwierdzenia,
- osoba zatwierdzajaca.

Przyklady typow materialow:

- logo klienta,
- zdjecie osoby,
- zdjecie biura,
- case study,
- cytat,
- font,
- ilustracja.

## 17. Struktura katalogow po naszej stronie

Po otrzymaniu materialow uporzadkujemy je w projekcie:

```txt
assets/source/
  figma/
  brandbook/
  fonts/
  photos/
  logos/
  client-logos/
  ai-illustrations/
  webflow/
```

Po optymalizacji finalne pliki trafia do:

```txt
public/
  brand/
  fonts/
  images/
  logos/
  client-logos/
```

## 18. Minimalna paczka startowa

Do rozpoczecia prac potrzebujemy minimum:

- [ ] Link do Figma brandbooka.
- [ ] Logo Persooa w SVG.
- [ ] Fonty lub nazwy fontow z licencja.
- [ ] Paleta kolorow.
- [ ] Zdjecia firmowe lub informacja, ze beda dostarczone pozniej.
- [ ] Logotypy klientow lub lista klientow do pokazania.
- [ ] Potwierdzenie, ktore logotypy klientow mozna publikowac.
- [ ] Link do Webflow.
- [ ] Informacja, czy Webflow jest finalnym contentem.
- [ ] Preferencje stylu ilustracji AI.
- [ ] Decyzja: dark sections czy pelny dark mode.

## 19. Pelna paczka idealna

Idealnie klient dostarcza:

- [ ] Figma brandbook z dostepem.
- [ ] Finalne logo w SVG.
- [ ] Wszystkie warianty logo.
- [ ] Favicon.
- [ ] Fonty `.woff2`.
- [ ] Licencje fontow.
- [ ] Finalna paleta kolorow.
- [ ] Zasady typografii.
- [ ] Zdjecia zespolu.
- [ ] Zdjecia biura.
- [ ] Zgody na publikacje wizerunku.
- [ ] Logotypy klientow w SVG.
- [ ] Arkusz zgody na publikacje logotypow.
- [ ] Logotypy partnerow technologicznych.
- [ ] Materialy do case studies.
- [ ] Zgody na publikacje wynikow case studies.
- [ ] Nowy content z Webflow.
- [ ] Assety z Webflow.
- [ ] Referencje stylu ilustracji AI.
- [ ] Decyzja dotyczaca dark mode / dark sections.
- [ ] Dokument z prawami do materialow.

## 20. Czego prosimy nie dostarczac jako finalnych plikow

Prosimy nie traktowac jako finalnych:

- screenow logo zamiast SVG,
- niskiej jakosci zdjec z komunikatorow,
- fontow bez licencji,
- logotypow klientow bez zgody,
- plikow z losowymi nazwami typu `image1.png`,
- grafik z tlem, jezeli logo powinno byc przezroczyste,
- materialow, ktore sa robocze i niezatwierdzone.

Moga one byc dostarczone jako referencja, ale nie powinny trafic bezposrednio na strone produkcyjna.

## 21. Najwazniejsze zasady

- Logo najlepiej dostarczyc w SVG.
- Fonty musza miec licencje webowa.
- Zdjecia dostarczamy w jak najwyzszej jakosci.
- Logotypy klientow wymagaja zgody na publikacje.
- Case studies wymagaja zgody na publikacje wynikow.
- Webflow musi zostac zweryfikowany pod SEO i brandbook.
- Ilustracje AI powinny miec jeden spojny styl.
- Do produkcji trafiaja tylko materialy zatwierdzone i zoptymalizowane.
