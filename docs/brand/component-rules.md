# Component rules

Zasady dla komponentow UI:

- uzywamy Tailwind CSS,
- komponenty bazowe moga korzystac z shadcn/ui,
- kazdy komponent musi byc zgodny z tokenami design systemu,
- nie dodajemy przypadkowych kolorow poza tokenami,
- kazdy komponent interaktywny musi miec focus-visible,
- komponenty sekcyjne musza byc responsywne,
- nie tworzymy duplikatow komponentow bez powodu.

Glowne zrodlo zasad Tailwind Design System:

```txt
docs/10-tailwind-design-system.md
```

Przed tworzeniem pelnych widokow strony trzeba najpierw oprzec sie na atomach i layoutach opisanych w tym dokumencie.
