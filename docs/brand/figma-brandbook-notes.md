# Figma brandbook notes

Link do Figma brandbooka:

```txt
https://www.figma.com/design/DxKHo2LuaZA95RuTNmN8oY/Persooa_Rebranding?node-id=3101-28987&t=F3Ak2kHEMyrRT6Kh-1
```

Zakres do sprawdzenia:

- logo - brandbook zawiera logo mark, konstrukcje, clear space, warianty kolorystyczne, minimalny rozmiar i dobre/zle praktyki,
- kolory - brandbook zawiera palete podstawowa i gradient angular,
- typografia - brandbook wskazuje primary font jako Kanit; do potwierdzenia licencja i pliki webowe,
- komponenty - brandbook nie jest pelnym UI kitem strony, ale zawiera kierunek dla ikon, layoutow social i brand examples,
- ilustracje - brak kompletnego systemu ilustracji www; trzeba zdefiniowac nowy styl AI na bazie brandu,
- zdjecia - brandbook pokazuje kierunek: technologia, ludzie, praca, abstrakcja, harmonia,
- dark mode - brandbook wspiera dark sections przez Brand_Dark i warianty ikon/logo na ciemnym tle,
- spacing - brandbook zawiera clear space logo, ale wymaga dopracowania tokenow UI pod strone,
- zasady brandowe - przewodnie wartosci: Infinity / Symmetry / Balance / Integration / Process.

## Pierwsze obserwacje z brandbooka

Brandbook ma wyrazny, technologiczny charakter: ciemny granat, intensywny niebieski, biel, jasne tla, gradient angular oraz fotografie zwiazane z technologia, ludzmi i praca.

Kierunek wizualny dla strony:

- nowoczesny B2B MarTech,
- mocne dark sections,
- intensywny blue jako glowny akcent,
- duzo bieli i przestrzeni w sekcjach contentowych,
- zdjecia technologiczne i zespolowe,
- abstrakcyjne gradienty jako key visuale,
- proste ikony liniowe,
- unikanie przesadnie ozdobnych efektow.


## Typografia

Brandbook wskazuje:

```txt
Primary font: Kanit
Weights: Light, Regular, Medium, SemiBold
Charakter: Modern / Versatile / Multiple weights
```

Do potwierdzenia:

- pliki fontow `.woff2`,
- licencja webowa,
- czy Kanit stosujemy dla calej strony,
- czy potrzebujemy osobnego fontu pomocniczego dla dluzszych tekstow.

## Zasady logo

Brandbook zawiera:

- logo mark,
- clear space,
- warianty kolorystyczne,
- minimalny rozmiar,
- best practices.

Wstepna zasada dla strony:

- logo niebieskie na jasnym tle,
- logo biale na Brand_Dark,
- logo biale na Brand_Blue,
- nie uzywac logo na zbyt chaotycznym zdjeciu bez kontrastu,
- zachowac clear space zgodny z brandbookiem.

## Ikony

Brandbook zawiera zestawy ikon:

- na jasnym tle,
- na ciemnym tle,
- na niebieskim tle.

Wstepna zasada dla strony:

- ikony liniowe,
- rozmiary bazowe 24/32/40 px,
- kolor zalezy od tla: Brand_Blue, White lub jasny wariant,
- ikony powinny byc stosowane konsekwentnie w kartach kompetencji, oferty i kanalow.

## Fotografia

Kierunek z brandbooka:

```txt
Abstract / Harmony / Technology / People / Work
```

Wstepna zasada dla strony:

- zdjecia maja wspierac technologiczny i profesjonalny charakter,
- preferujemy zdjecia realnego zespolu/biura oraz abstrakcyjne ujecia technologiczne,
- nie stosujemy generycznych stockowych portretow,
- zdjecia moga byc laczone z blue overlay, gradientem lub prostymi geometrycznymi maskami.
